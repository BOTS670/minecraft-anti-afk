# Minecraft Anti-AFK

Локальное desktop-приложение для Windows (Electron). Периодически выполняет простое действие
в выбранном клиенте Minecraft Java Edition: поворот камеры, небольшой шаг или прыжок.
Без веб-сервера и Vite. Не собирает телеметрию и не запускается вместе с Windows.
Сетевые запросы используются только для необязательной проверки новых релизов GitHub.

## Требования

- Windows 10/11 с Windows PowerShell 5.1 (встроен в систему)
- Node.js 22.12+ и npm (не нужны для готового `.exe`)
- Запуск **от обычного пользователя**. Права администратора не нужны

## Установка и запуск

```powershell
cd minecraft-anti-afk
npm install        # ставит Electron и инструменты сборки
npm start          # запуск приложения
npm run check      # проверка синтаксиса всех файлов
npm test           # unit-тесты (node:test)
npm run dist:portable # сборка портативного Windows exe в release/
```

Готовый `release/Minecraft-Anti-AFK-1.1.0-portable.exe` запускается без Node.js и установки.
Сборка поддерживает Windows x64; PowerShell-скрипты находятся рядом с `app.asar`, чтобы
обнаружение клиента и ввод работали в портативной версии.

## Как пользоваться

1. Запустите Minecraft и откройте мир. Курсор должен быть захвачен игрой (вы управляете персонажем, меню не открыто).
2. Нажмите «Обновить список» и выберите клиент.
3. Выберите режим и интервал (5–3600 с).
4. Нажмите «Запустить». В окне видны клиент, режим и обратный отсчёт.
5. «Остановить» прекращает действия. Они прекращаются сами, если процесс Minecraft закрылся
   или если 3 действия подряд не удались.

## Как это работает

- **Поиск клиентов:** `scripts/list-clients.ps1` берёт процессы `java.exe`/`javaw.exe` с видимым окном,
  у которых в заголовке есть «Minecraft» или в командной строке есть признаки Minecraft.
  Командная строка не передаётся в приложение, потому что в ней бывают токены доступа.
- **Ввод:** `scripts/send-input.ps1` активирует окно выбранного процесса и отправляет ввод через `SendInput`
  (клавиши по скан-кодам, мышь как относительное смещение). Затем возвращает прежнее активное окно.
  Если окно не удалось активировать, **ввод не отправляется**.
- **Слежение за процессом:** раз в секунду `process.kill(pid, 0)` (проверка существования, процесс не трогается)
  и повторная проверка перед каждым действием.
- **Таймер:** считает от плановой отметки, поэтому дрейф не накапливается. Пропущенные тики не догоняются.

## Проверка обновлений

В нижней части окна можно вручную проверить новую версию или включить автоматическую проверку
(по умолчанию — один раз через 5 секунд после запуска, затем раз в 6 часов). Если найден новый релиз
с portable EXE и SHA-256, приложение спрашивает пользователя и показывает кнопки «Установить» и «Отмена».
Скачивание и установка начинаются только после явного нажатия «Установить».

Перед заменой приложение скачивает EXE во временную папку и сверяет размер и SHA-256 с данными
GitHub Releases API. При несовпадении файл не устанавливается. Для замены portable-файла приложение
закрывается, помощник PowerShell ждёт завершения процесса, атомарно заменяет EXE и запускает новую
версию. Автоустановка доступна только в собранной portable-версии; при `npm start` можно проверить
обновление и открыть страницу релиза, но кнопки установки не будет.

Проверка включена для `BOTS670/minecraft-anti-afk`; для следующих версий публикуйте GitHub Releases
с тегами `vMAJOR.MINOR.PATCH` и portable EXE с ожидаемым именем
`Minecraft-Anti-AFK-<версия>-portable.exe`. При включённой проверке GitHub получает IP-адрес и User-Agent;
никаких игровых данных приложение не отправляет.

## Безопасность

`contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`, CSP без inline-скриптов, запрет навигации,
новых окон и разрешений. Preload открывает 11 функций. Каждый IPC-вызов проверяется: отправитель должен быть
нашим окном и нашим `index.html`; `pid`, режим и интервал валидируются; PID принимается, только если он
найден как клиент Minecraft. PowerShell запускается через `execFile` с массивом аргументов (без shell).
`-ExecutionPolicy Bypass` действует только на этот дочерний процесс и только для скриптов из папки `scripts/`.

## Ограничения

- **Окно выходит на передний план.** Игра принимает ввод только в активном окне, поэтому на время действия
  (~0,3–0,6 с) оно активируется, затем возвращается предыдущее. Это заметно, если вы работаете в другом окне.
  Нельзя использовать, пока вы печатаете: нажатия могут перемешаться.
- **Активация окна не гарантирована.** Windows ограничивает смену фокуса. Приложение использует обходной приём
  (короткое нажатие Alt), но при полноэкранных играх, игровых оверлеях или запущенном от администратора
  Minecraft она может не сработать. Тогда будет ошибка в «Последнем действии». Если игра запущена с повышенными
  правами, приложение тоже нужно запускать так же, иначе Windows (UIPI) блокирует ввод.
- **Игра должна быть «в мире».** В меню, чате или паузе камера, шаг и прыжок не сработают.
- **Поворот камеры** отправляет небольшое смещение мыши и возвращает его. Если игра не захватила курсор, смещение уйдёт в сам курсор.
- **Определение клиента** основано на эвристике (заголовок окна и командная строка). Лаунчеры с нестандартным
  заголовком могут не найтись или попасть в список лишние клиенты.
- **PID может быть переиспользован** после закрытия процесса. Перед отправкой ввода скрипт ещё раз проверяет,
  что это `java`/`javaw` с окном, но различить два разных Java-процесса не может.
- **Правила серверов.** Многие серверы запрещают AFK-боты и автоматизацию ввода; это может привести к бану.
  Используйте только там, где это разрешено (одиночная игра, свой сервер).
- PowerShell-скрипты содержат только ASCII для совместимости с Windows PowerShell 5.1; ошибки отображаются по локализованным кодам.
- Portable EXE не подписан сертификатом издателя; Windows SmartScreen может показать предупреждение. SHA-256 проверка не заменяет цифровую подпись.
- Портативная сборка не является установщиком и не создаёт ярлыки в меню «Пуск».
- Поддерживается только Windows.
